# FRAME — Web制作サービス サイト（モック）

中小事業者向けWeb制作サービス「FRAME」のマーケティングサイトのモックです。
（VRTX STUDIO / REVER とは別ブランド。明るい・気軽・速い、を担う集客用サイト）

## 現状
- `index.html` … CSS / JS をすべて含む**自己完結の1ファイル**。ビルド不要、ブラウザで直接開けます。
- 画像・外部アセットなし。外部依存は Google Fonts（Geist / Noto Sans JP）のみ。
- 動的要素：料金のライブプレビュー（オプション選択で見た目と合計が変化）、制作事例の手動カルーセル（矢印・ドラッグ・スクロール＋自動送りは操作で停止）、スクロールリビール、ヒーローのオーロラ・アニメーション。

## デザイン方針（確定）
- 配色：メタルシルバーの地 ＋ 宝石エメラルド（アクセント）＋ オーロラ・グラデ（ヒーロー主役）＋ コーラル（差し色）。
- 金（gold）= REVER専用 / ネオン紫・シアン = VRTX専用 → **FRAMEでは使わない**。
- 書体：Geist + Geist Mono + Noto Sans JP。
- レイアウトは確定。中身（写真・文言・実績）は差し替え前提のプレースホルダー。

## この先の方向
- 本番は **Next.js + TypeScript + Tailwind**、静的書き出し → **Cloudflare Pages / Vercel**（サーバー/DBなし）。
- このモックを土台に、各セクションをコンポーネント化していく想定。
- 制作事例カルーセルの「デモを見る」リンク先 = 同ドメインのサブパス（例 `/demo/salon`）に業態別デモページを追加していく。
